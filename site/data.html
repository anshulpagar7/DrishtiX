What it learns from

DrishtiX trains and evaluates on VRSBench, a versatile vision-language benchmark for remote sensing image understanding (NeurIPS 2024). It is built on the DOTA-v2 and DIOR imagery collections, and every caption in it was checked by a human rather than accepted from a model.

Images, each with a human-verified detailed caption
52,472

123,221

Tasks in one dataset: captioning, grounding, VQA

Why one dataset spanning three tasks matters

The same images can be asked to describe, to locate, or to answer — and something has to decide which is being requested. That is the entire argument for building a router rather than a wrapper, and VRSBench is what makes it testable: one image set, three ground truths. huggingface.co/datasets/xiang709/VRSBench

Task mixture

Set in training/configs/training.yaml. Without an explicit mixture the model learns whichever annotation type is most numerous and quietly stops doing the others.

Honest note on scale

The default run caps at 4,000 samples, not the full benchmark. That is a deliberate hackathon choice: get an adapter that works end to end, then scale. Any number reported from a 4k subset should be described as exactly that — an evaluator will ask, and “we trained on a filtered subset to get the pipeline working” is a much better answer than a figure that cannot be reproduced.
